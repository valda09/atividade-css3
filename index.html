O que aprendemos em AMC?

Algoritmos

São sequências de instruções organizadas para resolver problemas ou realizar tarefas. Eles ajudam a entender como um programa deve funcionar passo a passo.

Lógica de programação

É a forma de organizar o raciocínio para criar soluções. Utiliza decisões, condições e sequências para que o computador execute determinadas tarefas.

Modelagem

Consiste em representar uma situação ou problema de forma organizada, facilitando seu entendimento e a criação de uma possível solução.
